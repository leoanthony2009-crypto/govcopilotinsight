See the example briefing first

Choose your school's IDSR (Inspection Data Summary Report) file and get a one-page briefing, a full briefing with questions for governors, and an editable Word copy. Built and checked mainly on primary school IDSRs. Secondary IDSRs load but have had little testing, so check those briefings with extra care. Special schools are not yet supported.

  • No AI. Fixed rules read the tables; the same file always gives the same briefing.
  • No upload. The file is read in this browser and is never sent anywhere.
  • Traceable. Every headline points to its row in the IDSR.

How to get the file
  1. On a laptop or desktop computer, sign in to the IDSR site (idsr.ofsted.gov.uk) through DfE Sign-in and open your school's IDSR.
  2. Choose Download this page, or in your browser press Ctrl+S (⌘S on a Mac) and pick Webpage, HTML only.
  3. Choose the saved .html file here. The PDF version will not work.

Governor without a DfE Sign-in account? Ask your headteacher or clerk for the file. You can send them this message:

Please could you send me our school's latest Ofsted IDSR as a web page file? Sign in to the IDSR site through DfE Sign-in, open our school's IDSR, press Ctrl+S (or ⌘S on a Mac) and choose "Webpage, HTML only". The file name will end in .html. Please share it securely, as the IDSR is confidential. Thank you.

    How it's checked

    Checked against the IDSR. If your IDSR is newer than that, the briefing still loads but carries a warning.

    Tested before each release. At this version, 34 rule tests and 130 browser tests pass. They cover the number reader, banding and significance rules, small-number hiding, files that should be refused and files built to cause harm. It has not yet been validated against a large set of real IDSRs.

    For data protection officers. The page is static. The IDSR is opened by the browser on the user's own device and is never transmitted: the site's security policy stops this page sending data to any other site in the background, the code contains nothing that sends it to ours, and there are no cookies, analytics scripts or accounts. The supplier therefore never receives the school's data. Before first use, users sign up on a separate page with their name, school, role and email; this page then reads one marker in the browser's local storage, holding only the date of sign-up, so that it does not ask again. The marker is never sent anywhere. The site is hosted on Netlify, which, like any web host, keeps ordinary visit logs (such as the IP address and time of each visit).

    How the headlines are made. Every rule is written out in the method note, with one headline traced from the IDSR row to the sentence.

    Who built it. Built by a serving headteacher, so that governors can use the IDSR without reading all of it.

    About, privacy and limits

    Your data stays on this device. The IDSR is read in your browser only; nothing is sent to us or stored, and the site's security policy stops this page sending data to any other site in the background. No AI is used. The school or trust remains responsible for the IDSR and everything made from it, and Ofsted's IDSR conditions of use apply to anything you print or share.

    This briefing supports governor scrutiny. It does not replace the original IDSR or professional judgement, and it is not an Ofsted judgement, grade or prediction. Bandings and significance are reproduced from the IDSR; every headline carries a reference to its source row in the evidence trail. Small cohorts move percentages a lot: check the pupil numbers (n) before drawing conclusions.
