Accessibility statement

Last updated 14 November 2026. This statement covers governorbrief.co.uk.

What we aim for

We want as many people as possible to be able to use this site. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

What should work

  • Text and buttons have strong colour contrast, in both light and dark mode.
  • Body text is at least 16 pixels, and you can zoom the page to 200% without losing content.
  • Everything can be reached and used with a keyboard, with a visible focus outline.
  • Buttons and links are at least 44 pixels high for touch.
  • Headings, lists and tables are marked up so that screen readers can announce them.
  • Messages such as "tick this box" are announced to screen readers.

What we know does not work well

  • On a phone, the wider tables in a briefing scroll sideways inside their own box.
  • The one-page briefing is designed for A4 paper and uses small print. On screen you can zoom in, or use the full briefing or the Word copy, which use larger text.
  • The sample briefings are PDF files and have not been fully tagged for screen readers. The same content is available on screen by choosing Load example school.
  • The Word download has not been tested with every screen reader.

How this site was tested

The site is checked before each release with automated tests for text size, touch-target size, keyboard focus and layout at phone, tablet and desktop widths. It has not yet had an independent accessibility audit or testing with disabled users.

Report a problem or ask for another format

Email enquiry@governorbrief.co.uk and say which page and what went wrong. We aim to reply within five working days.

GovernorBrief is an independent tool. It is not affiliated with, endorsed by or produced by Ofsted or the Department for Education, and it does not replace the IDSR.
